Plane curves in Differential Geometry

Differential geometry
Cycloid, trochoids, epicycloids, hypocycloids and Bernoulli’s lemniscate: each curve traced by a rolling circle, with its parametrization read off the picture.
Published

October 12, 2026

How do we find equations for a curve that is defined by a motion? For the cycloid and its relatives the answer is in the picture: follow the point \(P\) while the circle rolls, project it on the axes, and use that rolling without slipping turns arc length into distance. The construction and the figure and equation numbers follow K. Frensel and J. Delgado, Geometria Analítica II, Aula 3 (IM-UFF).

These curves are also the first examples of the note Introduction to differential geometry: plane curves and initial concepts, which computes their singular points and the length of an arch of the cycloid.

How the code works

1. Each curve is a function of its parameter

def trochoid(r, R):
1    return lambda t: (r * t - R * math.sin(t), r - R * math.cos(t))


def epicycloid(R, r):
    k = (R + r) / r
2    return lambda th: ((R + r) * math.cos(th) - r * math.cos(k * th), (R + r) * math.sin(th) - r * math.sin(k * th))


def hypocycloid(R, r):
    k = (R - r) / r
3    return lambda th: ((R - r) * math.cos(th) + r * math.cos(k * th), (R - r) * math.sin(th) - r * math.sin(k * th))


def lemniscate(t):
4    return (t / (1 + t**4), t**3 / (1 + t**4))
1
A circle of radius \(r\) rolls on the \(OX\)-axis and \(P\) is at distance \(R\) from its centre: \(x=rt-R\sin t\), \(y=r-R\cos t\). With \(R=r\) this is the cycloid; \(R>r\) gives the prolate and \(R<r\) the curtate cycloid.
2
A circle of radius \(r\) rolls outside a fixed circle \(\Gamma\) of radius \(R\).
3
The same, rolling inside \(\Gamma\).
4
A rational parametrization of Bernoulli’s lemniscate.

Each function returns another function (a lambda), so trochoid(1, 1) is the cycloid and can be passed around, evaluated or drawn.

3. Labels that never touch the figure

Every label (\(P\), \(O_2\), \(\mathcal C_1\), angles, …) is placed by a small class, Placer, against the finished figure:

class Placer:
    """Puts each label at the first position around its anchor that touches no stroke, dot or other label
    of the finished figure (the obstacles)."""
    # ...
    def place(self, m, anchor, prefs=(), buffs=(0.08, 0.13, 0.19, 0.26, 0.34, 0.46), register=True):
        base = [UR, UL, DR, DL, RIGHT, LEFT, UP, DOWN]
1        dirs = list(prefs) + [d for d in base if not any(np.allclose(d, q) for q in prefs)]
2        for bf in buffs:
            for c in self._spots(m, anchor, dirs, bf):
                m.move_to(c)
3                if self.is_free(m):
                    if register:
4                        self.boxes.append(_bbox(m))
                        self.max_buff = max(self.max_buff, bf)
                    return m
        m.next_to(anchor, dirs[0], buff=buffs[0])
        if register:
            self.boxes.append(_bbox(m))
            self.max_buff = 9.0
5        print("WARNING: no free place for label", getattr(m, "tex_string", "?"))
        return m
1
The preferred directions first, then the eight compass directions.
2
Positions close to the point first; further away only if needed.
3
is_free tests the label’s box against points sampled densely along every curve and line of the figure, every dot, and every label already placed.
4
A label that has been placed becomes an obstacle for the next ones.
5
If nothing is free, the script says so at render time, so no collision goes unnoticed.

It is used like this, in the cycloid construction:

4. Galleries: one number drives several curves

1            def rolling(ax=ax, f=f, Theta=Theta, oc=oc, r=r):
2                v = lam.get_value() * Theta

                              circ(ax, O2, r, CIRC2, 2), sline(ax, O2, f(v), WHITE, 1.8),

        # ...
3        self.play(lam.animate.set_value(1.0), run_time=9, rate_func=linear)
1
The default arguments freeze the values of the current panel. Without them, every panel would use the values of the last one, a classic pitfall of functions defined inside a loop in Python.
2
One tracker \(\lambda\in[0,1]\) drives all panels, each up to its own final angle \(\Theta\), so curves that need more turns to close still finish at the same time.
