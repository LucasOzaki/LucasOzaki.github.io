A δ-fine tagged division

Kurzweil integral
Visualizing gauges and Cousin’s lemma, the starting point of the Kurzweil integral.
Published

October 11, 2026

What you see. A gauge \(\delta\) (blue) assigns to each point \(t\in[0,1]\) a radius \(\delta(t)>0\). A pair \((\tau,[s_{i-1},s_i])\) is \(\delta\)-fine when the bar \((\tau-\delta(\tau),\tau+\delta(\tau))\) drawn under the axis covers the whole subinterval. The first attempt (red) fails; then a \(\delta\)-fine division is built one pair at a time. For the mathematics, see the note Gauges, fine divisions and the Kurzweil integral.

Made with Manim Community v0.22. The excerpts below are the key parts of the code, each followed by a short explanation.

How the code works

1. The gauge and a division that is fine by construction

def delta(t: float) -> float:
1    return 0.06 + 0.25 * t


def greedy_fine_division(a=0.0, b=1.0, factor=0.9):
    points, tags = [a], []
    s = a
    while s < b:
2        tags.append(s)
3        s = min(b, s + factor * delta(s))
        points.append(s)
    return points, tags
1
Any strictly positive function is a gauge. This one is small near \(0\), so the division must be finer there.
2
Each subinterval is tagged at its left endpoint, \(\tau_i=s_{i-1}\).
3
Stepping by less than \(\delta(\tau_i)\) guarantees \([s_{i-1},s_i]\subset(\tau_i-\delta(\tau_i),\tau_i+\delta(\tau_i))\). This is a constructive shortcut for this particular \(\delta\); Cousin’s lemma is what guarantees existence for an arbitrary gauge.

3. Drawing the interval \((\tau-\delta(\tau),\tau+\delta(\tau))\)

def ball(tag, color):
    r = delta(tag)
1    left, right = axes.c2p(tag - r, 0), axes.c2p(tag + r, 0)
    bar = Line(left, right, stroke_width=10, color=color).set_opacity(0.55)
    ends = VGroup(*[Line(UP * 0.12, DOWN * 0.12, color=color).move_to(p)
                    for p in (left, right)])
2    return VGroup(bar, ends).shift(DOWN * 0.75)
1
c2p (“coordinates to point”) converts mathematical coordinates into screen positions, so the bar has exactly the length \(2\delta(\tau)\) in the axes’ units.
2
The bar is drawn below the axis so it does not hide the subinterval it must cover.
